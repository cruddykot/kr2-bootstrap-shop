# kr2-bootstrap-shop

Учебный проект контрольной работы №2 по дисциплине
«Фронтенд и бэкенд разработка».

## Тема
Разработка интерфейса на CSS-фреймворке Bootstrap.

## Стек
- HTML5
- Bootstrap 5.3.3 (CDN: CSS + JS Bundle)
- Собственный `css/custom.css` для минимальных правок

## Структура
- `index.html` — главная (сетка, hero, преимущества, популярные товары)
- `catalog.html` — каталог (card, badge, alert, модалка)
- `product.html` — страница товара (card, breadcrumb, accordion, модалка)
- `order.html` — форма заявки (form-control, form-select, form-check, input-group)
- `css/custom.css` — минимальные переопределения
- `images/` — изображения проекта

## Использованные компоненты Bootstrap
- navbar (с dropdown)
- card
- btn / btn-outline-*
- badge
- alert
- modal
- form-control / form-select / form-check / input-group
- breadcrumb
- accordion
- сетка container / row / col-*
